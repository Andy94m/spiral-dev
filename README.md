\# Spiral Dev 🌀



Plataforma web para aprender C y C# con pedagogía en espiral:

cada tema retoma lo aprendido y suma dificultad progresiva.



\## Stack

\- Backend: C# .NET 9 Web API + EF Core

\- Frontend: React + TypeScript + Vite

\- Base de datos: PostgreSQL (Supabase)



\## Estructura

\- `src/SpiralDev.Api` — API REST

\- `src/SpiralDev.UI` — Aplicación React
